# Sadeem Aljehani - Personal Portfolio

A personal portfolio website showcasing my projects, experience, activities, and technical skills.

## Overview

The portfolio presents my work across software development, AI, robotics, and student activities. Each project has its own page with additional details, technologies used, and related certificates or achievements when available.

## Features

* Personal introduction and profile
* Projects showcase with dedicated pages for each project
* Detailed project information and technologies used
* Certificates and achievements related to projects
* Experience and activities
* Technical skills
* Contact section
* English and Arabic language support
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* Google Fonts

## Structure

* `index.html` - Main portfolio page
* `css/` - Stylesheets
* `js/` - JavaScript files
* `projects/` - Individual project pages
* `images/` - Images, logos, and other visual assets

## Purpose

This portfolio was created to bring together my academic projects, technical work, experience, and activities in one place.
